# jit-access-broker

Um broker de acesso privilegiado Just-In-Time (JIT), pequeno e bem testado, para um laboratório local
com recursos simulados. O usuário pede acesso elevado com justificativa, aprovadores decidem,
o acesso expira sozinho e todo evento vai para um log de auditoria append-only e à prova de adulteração.

> **Status:** em desenvolvimento inicial (scaffold). Ainda não utilizável.
> **Projeto de laboratório:** usuários simulados e sem autenticação real. Nunca use para proteger sistemas reais.
